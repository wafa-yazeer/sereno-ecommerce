# SERENO Genève • Master Horology Boutique & E-Commerce

A premier luxury watchmaker e-commerce application engineered for high-precision timepieces, mechanical complications, and horological collectors.

---

## 🌟 Key Features

- **Exquisite Horological Catalog**: Filter by Chronograph, Automatic, Diver, and Masterpiece editions with live search and price sorting.
- **Interactive Watch Explorer**: Zoomable high-resolution imagery, micro-engineering technical specifications, dial materials, and water resistance ratings.
- **Live Order Tracking**: Real-time status pipeline (`Pending` → `Processing` → `Shipped` → `Delivered`) with tracking numbers and courier milestones.
- **Boutique Admin Management**: Comprehensive back-office portal to manage inventory stock, add new watch models, process orders, and handle customer reviews.
- **Dynamic Shopping Cart & Privilege Coupons**: Promo discount validation, free Swiss insured priority shipping, and tax calculation.
- **Responsive Luxury Aesthetic**: Dark-mode horology palette with brushed champagne gold accents and fluid animations.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Motion, Lucide Icons
- **Backend & Store**: Node.js & Vite API Middleware (In-Memory Database & RESTful endpoints)
- **Deployment**: Vite SPA / Node.js

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or bun

### Installation

1. Clone your repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
   cd YOUR_REPOSITORY_NAME
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit:
   ```text
   http://localhost:3000
   ```

---

## 📦 Production Build

To create a production-ready bundle:
